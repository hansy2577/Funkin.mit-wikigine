custom notes speed

notes speed are not compatible with pysch engine notes speed or other engine


for make low notes speed : -0.9

for make it faster : 1.3+

the most minial notes speed is 0.35 ( really really slow ), i strongly not recommended to exceed this speed

risk to break notes scroll

characters/.FMC

a .FMC is the characters data where the animation/delay/scale even scripts are in ( just like characters.json if you know Pysch engine )

composition :

  "alt name":"boyfriend",  // character alt name
  "icon": "bf",  // icon folder
  "position": [0,0],   // character position ( in w.i.p )
  "scale": 1.3,    // scale
  "flipX ?": false,    // flip the position
  "Padding Length ?":true,  // use a xml frame naming animation or a default one-
  //exemple: "anim0.png >> anim19.png" xml : "anim0000.png >> anim0019.png"
